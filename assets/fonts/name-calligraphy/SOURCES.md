# Name calligraphy fonts

- Latin: Allura, from https://github.com/google/fonts/tree/main/ofl/allura
- Chinese: Ma Shan Zheng, from https://github.com/google/fonts/tree/main/ofl/mashanzheng

Both fonts are distributed under the SIL Open Font License; the licenses are included in this directory. Local WOFF files contain only the characters used in the homepage name. Generated with fontTools subset.

`juanxi-chinese-name.woff2` is an updated Ma Shan Zheng subset downloaded from the official Google Fonts API on 2026-10-22. It includes `（田隽熙）｜世憬` so the About Me alias uses the same calligraphy as the existing name. The original WOFF remains as a fallback.
