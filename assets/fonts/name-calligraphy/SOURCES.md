# Name calligraphy fonts

- Latin: Allura, from https://github.com/google/fonts/tree/main/ofl/allura
- Chinese: Ma Shan Zheng, from https://github.com/google/fonts/tree/main/ofl/mashanzheng

Both fonts are distributed under the SIL Open Font License; the licenses are included in this directory. Local WOFF files contain only the characters used in the homepage name. Generated with fontTools subset.

`juanxi-chinese-name.woff2` is an updated Ma Shan Zheng subset downloaded from the official Google Fonts API on 2026-10-22. It includes `（田隽熙）｜世憬` so the About Me alias uses the same calligraphy as the existing name. The original WOFF remains as a fallback.

- CSS source: https://fonts.googleapis.com/css2?family=Ma+Shan+Zheng&text=%EF%BC%88%E7%94%B0%E9%9A%BD%E7%86%99%EF%BC%89%EF%BD%9C%E4%B8%96%E6%86%AC&display=swap
- Font download: https://fonts.gstatic.com/l/font?kit=NaPecZTRCLxvwo41b4gvzkXaRMHsCoRTVKR9CfTYQ1RpOeZ5MP6W6dhYmH_uCHqWaKE&skey=13c999d73b164fc8&v=v18

The visible name keeps the spelling `田隽熙` as requested. This Ma Shan Zheng subset is the active Chinese name font, covering the complete name and alias with a consistent brush style.

## Alternative Traditional Chinese name font

`juanxi-name-hant.woff` uses LXGW WenKai TC, downloaded from the official Google Fonts API on 2026-10-22 and converted from its TrueType subset to WOFF with fontTools. It contains the Traditional Chinese spelling of the name and alias. It is retained as an alternative asset and is not currently used by the site.
